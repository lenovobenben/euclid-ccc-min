# 关于初始点与任意点的未决问题

> 状态：研究备忘，不具规范效力。
>
> 在本问题另行论证并作出明确决定以前，项目继续采用
> [研究设计](DESIGN.md)第 4 节已经冻结的确定点模型；本文不改变任何
> 已有定义、程序、计数、上界或搜索结论。

## 1. 问题从哪里产生

当前 E 模型要求画线和画圆所用的点已经存在，而除题目给定点外，新点
只能是已有直线或圆的确定交点。这个规则适用于当前 CCC profile：三个
圆心已经给定，可以先连接两个圆心，再由所得直线与输入圆相交取得圆周
点。Euclid-Min 的正十七边形 profile 同样给定圆心和一个圆周点，因此
也可以起步。

但是，若一个一般尺规题只说“给定一条直线和一个线外点”，却没有命名
直线上的点，当前形式语言甚至不能执行第一步。只给定一个没有圆心或
圆周点的圆时也有同类问题。这说明“抽象图元如何作为输入呈现”和
“作图过程中能否任取点”需要分开定义。

## 2. 三种需要区分的模型

### A. 确定点模型（项目当前采用）

- 每个 profile 明确列出免费初始点、直线和圆；
- 一项画线或画圆只能引用已有点；
- 新点只能来自已有对象的有限实交点；
- 不允许在平面、直线或圆上任取点。

本项目现有的 18 E、49 E、55 E 上界以及全部搜索边界都按此模型陈述。

### B. 输入见证点模型

题目在给出输入图元时，同时给出足够表示并使用该图元的点。例如，一条
输入直线附带线上定义点，一个带圆心的输入圆附带一个圆周点。构造开始
后仍只允许确定交点，不再产生新的自由点。

这里的见证点属于题目输入，而不是构造中的免费操作。其位置若不是原题
数据的一部分，就必须说明构造是否对所有一般位置的见证点成立。

### C. 已有对象上的免费一般点模型

作图过程中可以随时在任一已有直线或圆上引入新的一般点，并计 0 E。
这个模型允许不断引入新的自由参数，严格强于只在输入阶段附带有限个
见证点。若以后考虑它，还必须严格定义“一般点”，排除通过特殊选点把
切点、垂足、目标点或其它答案信息隐藏在 0 E 操作中的做法。

## 3. 为什么目前不能断言计数不受影响

三个模型都可以采用同一个表面公式

\[
E=\#\operatorname{Line}+\#\operatorname{Circle},
\]

但它们允许的程序集合不同。额外的 0 E 初始点可能恰好省去产生所需
方向或交点的步骤；动态免费一般点还会把有限的确定点闭包扩展为带自由
参数的程序空间。因此，“只要给足点使程序能够起步”可以解决形式语言
的起步问题，却不能单凭这一点推出三个模型具有相同的最优 E 值。

对于当前 CCC profile，只能立即确认以下事实：A 已经可以起步；任何 A
中的程序也是 B 或 C 中的合法程序（在相应扩张方式包含原有输入时）；
因而扩大合法程序集合不会使已知上界失效。反方向的等价以及最优值是否
保持不变，仍需证明或反例。

## 4. 将来若重启讨论，需要解决什么

1. 明确“给定直线”“给定圆”和“带圆心的圆”各自必须附带哪些命名点；
2. 明确输入见证点是固定输入数据，还是要求结论对其所有一般位置成立；
3. 比较 A 与 B：证明任一使用见证点的构造都能无额外 E 地消去这些点，
   或给出最优步数确实改变的反例；
4. 若考虑 C，用函数域或等价语义定义一般点，并规定正确性证明责任；
5. 若正式更换模型，重新审计历史构造的可比性和现有搜索的完备边界。

## 5. 当前处理决定

本议题暂不进入主研究路线。CCC 的正式计数继续使用 A；现有工作继续在
同一规则下优化 `CCC-ALL-8` 和 `CCC-EXT-1`。在有严格等价证明、明确
反例或项目另行决定以前，不把输入见证点或免费一般点写入正式规则。
